01 Brand in Context Color lives in the moments — not the UI
Lifestyle Color System
Color is never assigned from a fixed palette. It is derived from the subject — a savings story is gold, a review screen is cool blue-purple, a concert is orange. One dominant color per screen. 5–15% opacity. Always softened into the dark background.

Used for: wordmark, hero headlines, event collateral, campaign moments, poster copy.
Rules
✕  Never used in the app — not for UI labels, buttons, or any in-screen text
✕  Never below 18px — legibility breaks at small sizes
✕  Single weight only — do not simulate bold, condensed, or stretch
✓  Outlined variant for large-scale moments — posters, event signage, hero screens
✓  Always uppercase — the typeface is designed for this treatment

07 Do's & Don'ts
✓Use the gradient background — never a flat color
✕Substitute #000000 or any flat color for the background
✓Use warm brown rgba(39,32,29,0.4) for all shadows
✕Use cold/neutral black for shadows
✓Use white (#FFFFFF) for all interactive states and CTAs
✕Introduce a fixed accent color in the UI chrome
✓Let content drive color — one dominant per screen
✕Use brown for buttons or CTAs
✓Give screens room to breathe — screens exhale, not compress
✕Use Horizon for any in-app UI text
✓Use functional colors only when meaningful
✕Apply glass to dense or data-heavy screens
